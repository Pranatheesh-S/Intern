# Universal Visual & 3D Artwork Style Guide

## Core Aesthetic Principles
All generated images, 3D object models, background canvases, and UI components across all modules MUST adhere to this universal design system:

1. **3D Isometric & Tilt-Shift Perspective**:
   - Use high-detail, warm isometric 3D illustrations with cinematic lighting, ambient occlusion, and subtle depth of field.
   - Style: High-end 3D game asset / Pixar-like polished miniature model aesthetic.

2. **Color Palette & Lighting**:
   - **Environment Lighting**: Warm directional sunlight with golden ambient glows, soft ground shadows, and vibrant realistic materials.
   - **Canvas & Container Borders**: Warm ivory / cream background cards (`#FFFBEB` / `#FFFDF5`), `20px` border-radius, soft ambient drop shadows.
   - **Accent Buttons & Controls**: Vibrant warm amber-orange gradients (`linear-gradient(135deg, #F59E0B 0%, #D97706 100%)`) with white high-contrast text (`fontWeight: 900`).

3. **Asset Generation Rules**:
   - NEVER create flat 2D clip-art or primitive generic shapes.
   - Tailor every object (magnets, airplanes, maps, lab gear, compasses) to match this rich isometric 3D illustrated style without copying the city map content directly.
